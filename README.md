# Why Sudo?

> Keep tabs on us! We've got some exciting new features in the pipeline. Drop a ⭐️ on the repository to ensure you catch the latest releases.

> This application is currently in *Beta Development*.

In the wake of the massive influx of programs and applications suffering from "code bloat" appearing out of nowhere with the help of AI, the internet is filling up with "functional rubbish". I love coding as meticulously as possible (sure, I still have a lot to learn, but... I try).

**Why Sudo?** was born from a simple idea. Picture this: one day, you go to sleep exhausted after a heavy day of work or study, and the next morning, you realise that the *internet* is gone. I don't just mean your Wi-Fi signal dropping—the ENTIRE INTERNET is down. Across the globe, AI was the one generating code, making everyone [vibe coders](https://github.com/resources/articles/what-is-vibe-coding) except for you, because you never stopped hand-crafting your code. How would you rebuild the internet if everything was in ["the cloud"](https://www.cloudflare.com/learning/cloud/what-is-the-cloud/)? You probably have Linux on your laptop (if you're a bit of a geek ._.). Right, your next steps might look like this:

1. Plan a clear, optimised structure, complete with patterns and everything else.
2. Design the network and its wired infrastructure.
3. Define communication protocols.
4. Design smart contracts.
5. Head to your safe space (the `sudo` terminal).
6. And to kick off step 1, you type `sudo apt-update & apt upgrade`.
7. You get an error...
8. You open Brave and type "chatgpt.com"...
9. It doesn't load...

Exactly, the internet no longer exists. And... what was the error? Is it `apt-update` or `apt update`? Do you use a single `&` or a double `&&`? Is it actually `upgrade`, `apt-upgrade`, or `apt upgrade`? Right, you get the point.

There needs to be an **OFFLINE** tool to use as a reference for your most frequently used commands (or all of them, why not?).

That is exactly why **Why Sudo?** was created: a reference guide for `1,990+ Linux commands` containing usage syntax, parameters, and basic information. Most importantly, it is **OFFLINE**. There is absolutely no red tape—it's 100% yours, and to top it off, it's lightning-fast.

## Features

* Search for commands by exact name
* Search for commands by functionality (command keywords)
* Basic documentation for over 1,990 commands
* Add commands to your favourites
* View all available commands in a separate, sorted view
* View ONLY favourite commands in a separate, sorted view
* Copy commands to the clipboard
* Lightning-fast loading speeds

### FAQ

1. **Why is the database encrypted?** The original goal for this app was to navigate Google's bureaucracy (the Play Store) and generate sales, so I had to be a bit cautious.
2. **Why is it Open Source?** Primarily because I want to provide the Open Source community with an AI-FREE tool that is functional, fast, and optimised. Also, publishing it on the Play Store would take months, and I want the project to see the light of day as quickly as possible (right now).
3. **Why are there *free* and *pro* flavours?** The answer to question 1 covers this.
4. **Does it work on all Android devices?** The MINIMUM required Android version is "Android 7.0 Nougat" (API Level 24).
5. **What do I do if the app crashes or throws errors?** Feel free to report any bugs in the [issues](https://github.com/tutosrive/whysudo/issues) section.
